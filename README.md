# equilibra

# 🌍 EQUILIBRA
### Build Balance. Complete Missions. Become an Earth Keeper.

Equilibra is a full-stack mission-driven platform designed to transform real-world environmental and personal growth actions into an engaging journey.

Users progress through multiple life pillars by completing meaningful missions, earning scores, unlocking team collaboration, and evolving into an **Earth Keeper**.

> ⚠️ Project Status: Active Development (Approximately 60% Complete)

---

## ✨ Vision

Equilibra is being built to connect:
- Climate awareness
- Personal growth
- Gamification
- Community collaboration
- AI-driven experiences

The goal is to create an ecosystem where small real-world actions lead to measurable impact.

# ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/YOUR_USERNAME/equilibra.git
```

Move into project:

```bash
cd equilibra
```

---

## Install Frontend

```bash
cd frontend
npm install
npm start
```

Runs on:

```bash
http://localhost:3000
```

---

## Install Backend

```bash
cd server
npm install
npm run dev
```

Runs on:

```bash
http://localhost:5000
```

---

# 🔐 Environment Variables

Create:

```env
server/.env
```

Example:

```env
PORT=
DATABASE_URL=
JWT_SECRET=
REDIS_URL=
FIREBASE_KEY=
AI_API_KEY=
LOCATION_API=
CLIMATE_API=
```

Do not commit `.env`.
